# Exact federated feature screening

Research software and aggregate results for *Bytes and round trips in exact federated feature screening under temporal drift*, release **v1.0.0**.

The code compares exact top-k protocols over federated temporal streams. The implementations include lossless dense frames, TPUT, batched NRA, grouped residual screening, and stateful safe zones with partial repair. Aggregated costs and selection checks from the public, native-site and online experiments are in the four summary JSON files in `result/`. The online evaluation used Windows and WSL2 TCP stacks on one physical workstation.

## Verify and run the exactness pilot

The pinned environment was Python 3.13.2. From the repository root:

```sh
python -m pip install -r requirements-study.txt
python script/mve/run_cycle3.py pilot --slug reproduce-partial-pilot --workers 2
```

The five deterministic seeds exercise ties, dimensions, local repair and dense fallback. The runner records 21,420 protocol comparisons and checks the selected IDs against an independent rank computation. `MANIFEST.sha256` records the released file digests. On platforms with GNU coreutils, run `sha256sum -c MANIFEST.sha256`.

## Reproduce the held-out online study

The programs fetch their inputs from the providers and rebuild the fixed candidate dictionaries locally. Third-party datasets, station-level arrays, and serialized score frames are distributed only by their respective sources or generated by the study code. These inputs are outside this release's license. See [Data sources](data/SOURCES.md) for providers, version choices and the OpenML cache layout.

```powershell
python script/mve/run_cycle3.py heldout --slug reproduce-bike-heldout --policy-run 20261124-1431__online_development --data-root data/cache
python script/mve/run_cycle3.py ablation --slug reproduce-bike-ablation --policy-run 20261124-1431__online_development --heldout-run reproduce-bike-heldout
python script/mve/run_cycle3.py online --slug reproduce-online-wsl --policy-run 20261124-1431__online_development --heldout-run reproduce-bike-heldout
python script/mve/analyze_cycle3.py --dev 20261124-1431__online_development --heldout reproduce-bike-heldout --online reproduce-online-wsl --ablation reproduce-bike-ablation --data-root data/cache
```

The held-out stage generates two dictionaries from the official 2022 Capital Bikeshare archives. The online benchmark requires Windows with an Ubuntu WSL2 distribution, Python 3 and NumPy in that distribution, and TCP localhost forwarding. The shipped policy is fixed before the held-out stage. The program checks the exact output on every completed round; latencies depend on the host and scheduler.

The earlier battery entry points are `run_screening.py`, `run_exact_study.py`, and `network_screening.py`. Rebuilding the cycle 3 development policy from scratch also requires the earlier revised and scale score runs. Run the first two stages below with their archived slugs, which the development stage expects. The study comparisons use the fixed policies included here.

```sh
mkdir -p data/cache
python script/mve/fetch_streams.py --data-root data/cache --with-occupancy
python script/mve/run_screening.py revised --slug 20261124-1310__screen_revised --workers 2 --data-root data/cache
python script/mve/run_screening.py followup --slug 20261124-1303__screen_scale --workers 2 --data-root data/cache
python script/mve/run_cycle3.py development --slug reproduce-development --data-root data/cache
```

The 42 OpenML source IDs and final feature shapes are listed in `data/dataset_manifest.csv`. Provider ordering, missingness, train-only preprocessing, and source version affect the reconstructed study inputs.
